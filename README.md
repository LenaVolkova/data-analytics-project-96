The goal of this project is to analyze data on user sessions on the online school website and make conclusions on marketing campaigns efficiency.
Using DBeaver and SQL I’ve created a data mart based on the “Last Paid Click” attribution model to analyze website visit data. To assess revenue generated by users who visited the website via specific campaigns I calculated metrics such as CPU (cost per user), CLP (cost per lead), CPPU (cost per paying user), and ROI (return on investment). 
With BI-tool Preset.io I created a dashboard to show results and  answer questions such as how many users visit the website, which channels bring them there (by day/week/month), how many leads are generated, what is the click-to-lead and lead-to-payment conversion rate, how much is spent on different channels over time, and whether these channels are profitable. 
It provides recommendations on which channels should be disabled, which ones should be adjusted, how long it takes from the moment an ad clicks to close 90% of leads, and whether there is a correlation between the launch of an advertising campaign and organic traffic growth.
